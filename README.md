# textbook-tutor · 教材精讲私教

一个 WorkBuddy AI 技能插件：把任意教材变成「先诊断、后讲解、讲完就练、学完验收」的个性化小课。

## 它解决什么问题

- 拿到教材不知道从哪学起、自己学到什么程度
- 看教材时「一看就懂，一做就废」
- 学完一节说不清自己学了什么

这个插件让 agent 先摸清你对每个知识点的真实水平，再按水平定制讲解，并用一份持续更新的学习档案记住你的偏好、思维模式和常犯错误——学得越久，教得越准。

## 教学流水线

```
Phase 1  接入教材 → agent 快速识别学科与章节结构 → 询问学习起点（强制等待用户指定）
Phase 2  精读指定小节 → 输出完整知识点清单 → 建立学习档案
Phase 3  逐点循环：诊断填空题（交互组件）→ 判定 L0–L3 真实水平
         → 按水平定制讲解（生活化例子 + 幽默口吻）→ 讲完立即派巩固任务
Phase 4  合书自述总结 → 按量规评估 → 不合格针对性补习 → 合格后下发独立任务
         （生成小节过关卷，或推荐刷题资源）
```

每个环节都要求用户真实参与：起点由用户选、诊断由用户答、总结由用户写，agent 不代答、不跳过验收。

## 前端交互：填空诊断组件

讲解每个知识点前，agent 先出一道诊断填空题，由插件的前端交互组件渲染：

- 用户在填空输入框中作答，点击「提交答案」
- 组件调用 `sendPrompt()` 将答案作为新消息回传给 agent（协议格式：`【诊断题作答】知识点：X，我的答案：Y`）
- agent 据此判定水平（L0 零基础 / L1 似懂非懂 / L2 基本掌握 / L3 学有余力）并定制讲法

## 安装

将整个 `textbook-tutor` 目录放入用户级技能目录：

```bash
# Windows
xcopy /E /I textbook-tutor %USERPROFILE%\.workbuddy-ai\skills\textbook-tutor

# macOS / Linux
cp -r textbook-tutor ~/.workbuddy-ai/skills/
```

安装后在对话中提及「教材 / 精讲 / 辅导我学 / 学习档案」等触发词即可启用。

## 目录结构

```
textbook-tutor/
├── SKILL.md                              # 主流程：四阶段教学流水线与红线
├── references/
│   ├── teaching-playbook.md              # 教学法：出题原则、水平判定量规、分策略讲解、验收量规
│   └── quiz-widget-html.md               # 填空诊断组件 HTML 模板与 sendPrompt 回传协议
└── assets/
    └── learning-state-template.md        # 学习档案模板（状态表 + 用户画像 + 策略调整记录）
```

## 使用方式

对 agent 说：「帮我学这本教材」，然后上传或指定教材文件（PDF / Word / 图片 / 文本均可）。agent 会先汇报学科定位，问你想从哪一节开始——指定后即进入完整的诊断—讲解—巩固—验收循环。

## 备注

- 学习档案保存在当前工作区 `学习档案/<教材名>-学习档案.md`，跨会话持续生效
- 本仓库仅包含技能定义文件，不含任何本地隐私信息
